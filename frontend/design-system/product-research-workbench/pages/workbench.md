# 产品研究工作台：页面设计覆盖规范

本文件覆盖 MASTER.md 中与本项目不符的通用建议。依据 UI UX Pro Max 查询 `workflow automation dashboard --design-system`，并结合现有 V2.1 方案制定。

## 适用范围

任务中心、流程工作台、人工确认和产物证据页面。仅使用 UI UX Pro Max Skill。第一阶段采用 React + TypeScript + Vite；流程图使用 SVG 连线与原生按钮，不依赖 React Flow Skill 或 React Flow 包。

## 信息架构

- 本项目是日常研究工具。通用查询返回 Operations Landing，取其状态清晰原则；营销 Hero、试用 CTA、社交证明不适用于本页面。
- 任务中心回答：哪些任务执行中、为什么等待、谁占用资源、哪里需要确认。
- 工作台回答：当前位于哪一节点、上下游关系、下一步可执行什么。
- 工作台使用两排连续路径：上排从左向右，下排从右向左，编号与箭头共同表达顺序。
- 当前业务演示保留阶段串行依赖。多任务并发通过任务中心体现，不凭空增加单任务并行边。
- 新增机会 Agent、交付 Agent 和扩展审核明确标注规划；已有 Python 步骤显示映射。

## 视觉规范

使用 CSS 语义变量统一深浅主题：

| 用途 | 深色 | 浅色 |
|---|---|---|
| 页面背景 | #10151E | #F4F6F9 |
| 内容表面 | #171E29 | #FFFFFF |
| 主文字 | #E8EDF5 | #172338 |
| 次级文字 | #A2AEC0 | #536176 |
| 辅助文字 | #8593A9 | #606E82 |
| 主要操作 | #EDBD70 | #795021 |
| 完成状态 | #7AD3B3 | #176449 |
| 执行状态 | #9EBCF9 | #2F599E |
| 人工确认 | #EFC17E | #785017 |

- 主操作采用低饱和琥珀色，完成用绿色，执行用蓝色；状态始终伴随文字或图标。
- 中文界面使用本地 Segoe UI / Microsoft YaHei UI / PingFang SC，避免依赖远端字体；任务 ID 与数字使用等宽/等宽数字。
- 标题 25–29px，节点标题 14px，正文与辅助文字按信息层级区分；移动输入框 16px。
- 间距以 4/8px 为基础；仅在节点和浮层使用克制阴影。普通列表通过分隔线建立秩序。
- Lucide SVG 图标保持一致线宽，不使用 Emoji 充当结构图标。

## 交互与可访问性

- 图中每个节点都是可聚焦按钮。缩放和列表替代操作避免依赖拖拽；手机默认列表。
- 模态详情使用原生 dialog 保持焦点约束和 Escape 关闭，未保存编辑必须显式放弃。
- 页签支持左右方向键；搜索空态可清除筛选。
- 确认绑定已保存的词表版本。修改未保存时禁用确认；空规范值禁用保存与确认。
- 只在执行连线上表达运行变化；prefers-reduced-motion 下关闭动画。
- 375/768/1024/1440 宽度进行响应式检查。画布内部可滚动，页面整体不应横向溢出。

## 第一阶段边界

全部任务与事件保存在 React 内存中，刷新复位；不读取配置，不执行采集、不调用 LLM，不产生真实业务报告。并发状态机只用于验证产品交互，不能承担生产任务锁或租约。
