# 步骤 15：选品指标定级与五档结论判定标准

> **最后更新**：2026-11-26  
> **代码实现出处**：
> - 指标计算与默认阈值：`tools/step15_market_assessment.py`
> - 维度定级、五档判定与 AI 建议提示词：`tools/step15_indicator_assessment.py`
> - 报告数据接口、PDF 与 WebUI 同源展示：`core/step15_review.py`、`core/step15_pdf.py`、`webui/index.html`

## 一、设计原则

1. **按独立业务维度而非机械数总项数判定**：避免把同源指标重复计票（如 VC/卖家/品牌同归「垄断与自营控盘」，大卖/评论/老品同归「评价与冷启动壁垒」）。
2. **需求规模与经营约束分离**：将需求端拆分为 **A1. 需求底盘（规模与趋势）** 与 **A2. 经营约束（CPC / 客单价 / 季节波动）**，避免将高门槛但有真实需求的类目误判为“没需求”。
3. **动态联动工作台阈值**：各维度轻/中/重/极端偏离度均基于工作台当前生效阈值 `lim` 自动计算（下表同时给出默认阈值对应的参考值）。
4. **确定性拆解 + AI 解读同源**：PDF 报告与 WebUI 均在「能否进入」下方直接展示由代码确定性生成的 **A1 / A2 / B / C / D 判定拆解表**与 `规则判定参考`，避免模型表述漂移。

## 二、单指标达标标准与维度定级规则（共 21 项：19 项参与判定 + 2 项仅展示）

### 1. 维度 A1：需求底盘（规模与趋势，6 项）

| 指标 | 计算口径 | 默认达标标准 (`lim`) | 维度定级规则 |
| :--- | :--- | :--- | :--- |
| **核心词搜索量** | 步骤 8 生效核心词中筛选搜索量 > 阈值且 CPC < 阈值的词 | `> 30,000 次/月` | **单项不达标 → 直接判「不成立」** |
| **核心词数量** | 满足搜索量及 CPC 条件的生效核心词个数 | `> 2 个` | **单项不达标 → 直接判「不成立」** |
| **类目GMV估算** | 步骤 14 样本变体月销额之和（样本口径，非全市场） | `≥ USD 100,000/月` | **单项不达标 → 直接判「不成立」** |
| **月需求量估算** | 步骤 14 样本变体月销量合计 ÷ 样本变体数 | `≥ 500 件/变体/月` | 不达标 → 判「偏弱」（`< 0.6×lim` 即 `< 300` 记入突出不达标项） |
| **趋势方向（站内）** | 达标核心词近 3 个月合计搜索量同比均值 | `> -20%` | 单项不达标 →「偏弱」（且不得评「可进入」）；**与 Google 同时不达标 → 判「不成立」** |
| **趋势方向（Google）** | 核心词 Google 指数同月相加后近 3 个月同比均值 | `> -20%` | 单项不达标 →「偏弱」；**与站内同时不达标 → 判「不成立」** |
| *旺季月份 / 淡季月份* | *有季节性时取近 24 个月合计搜索量最高/最低 3 个月* | *仅展示* | 不参与判定 |

**A1 汇总定级**：
- **数据不足**：需求端有效已判定指标 `< 3` 项（总项 ≥ 3 时）或为 0；
- **不成立**：命中任一硬红线（核心词搜索量 / 核心词数量 / 类目GMV估算 不达标，或站内+Google 趋势双双不达标），或核心 6 项不达标 `≥ 3` 项；
- **偏弱**：未触发「不成立」，核心 6 项有 1–2 项不达标；
- **健康**：核心 6 项全部达标。

---

### 2. 维度 A2：经营约束（成本 / 毛利 / 备货资金门槛，3 项）

| 指标 | 计算口径 | 默认达标标准 (`lim`) | 维度定级规则 |
| :--- | :--- | :--- | :--- |
| **CPC竞价** | 已筛选核心词的最高 CPC | `< USD 3` | 3 项独立汇总定级：<br>• 0 项不达标 → **可控**<br>• 1 项不达标 → **轻度约束**<br>• 2 项不达标 → **中度约束**<br>• 3 项全不达标 → **高约束** |
| **平均客单价** | 步骤 14 样本变体价格算术平均 | `> USD 35` | 同上 |
| **季节波动系数** | 达标核心词每月搜索量相加，近 24 个月拆为两个连续 12 个月，取两年峰谷比中较大值 | `≤ 2.5` | 同上 |

### 3. 维度 B：垄断与自营控盘（4 项，取最高等级）

| 指标 | 计算口径 | 默认标准 (`lim`) | 轻度 | 中度 | 重度 | 极端 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **VC卖家占比** | 配送方式为 AMZ 的样本变体销额 ÷ 样本总销额（自营近似口径） | `< 20%` | `20% ~ <35%` | `≥ max(35%, 1.75×lim)`<br>（默认 `35%`） | `≥ max(50%, 2.5×lim)`<br>（默认 `50%`） | `≥ max(70%, 3.5×lim)`<br>（默认 `70%`） |
| **头部品牌集中度** | 前 5 品牌样本销额 ÷ 样本总销额 | `< 60%` | `60% ~ <70%` | `≥ lim + 10pct`<br>（默认 `70%`） | `≥ lim + 15pct`<br>（默认 `75%`） | `≥ lim + 25pct`<br>（默认 `85%`） |
| **卖家集中度** | 前 5 BuyBox 卖家样本销额 ÷ 样本总销额 | `< 60%` | `60% ~ <70%` | `≥ lim + 10pct`<br>（默认 `70%`） | `≥ lim + 15pct`<br>（默认 `75%`） | `≥ lim + 25pct`<br>（默认 `85%`） |
| **头部链接销售额占比** | 前 5 变体 ASIN 销额 ÷ 样本总销额 | `< 60%` | `60% ~ <70%` | — | `≥ lim + 10pct`<br>（默认 `70%`） | `≥ lim + 20pct`<br>（默认 `80%`） |

**同维叠加升级**：
- 维度 B 有 `≥ 2` 项不达标 → 至少升为 **中度**；
- `VC卖家占比 ≥ max(40%, 2×lim)`（默认 `40%`）**且** 叠加 `头部品牌集中度` 或 `卖家集中度` 不达标 → 升为 **重度**。

### 4. 维度 C：评价与冷启动壁垒（4 项，取最高等级）

| 指标 | 计算口径 | 默认标准 (`lim`) | 轻度 | 中度 | 重度 | 极端 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **评论壁垒** | 按父 ASIN 汇总变体月销量，前 10 父体各取最大评分数求算术平均 | `< 5,000 条评分` | `5,000 ~ <6,500` | `≥ 1.3×lim`<br>（默认 `6,500`） | `≥ 2.0×lim`<br>（默认 `10,000`） | `≥ 4.0×lim`<br>（默认 `20,000`） |
| **大卖占比** | 评分数 > 1000 的样本变体销额 ÷ 样本总销额 | `< 50%` | `50% ~ <65%` | `≥ lim + 15pct`<br>（默认 `65%`） | `≥ lim + 25pct`<br>（默认 `75%`） | — |
| **上架超3年链接销额占比** | 上架 > 1095 天样本变体销额 ÷ 有效样本总销额 | `< 70%` | `70% ~ <80%` | `≥ lim + 10pct`<br>（默认 `80%`） | — | — |
| **评分** | 样本有效变体评分算术平均（0 视为无有效评分） | `≥ 4.2 分` | `< 4.2 分` | — | — | — |

**同维叠加升级**：
- `大卖占比` 与 `评论壁垒` 同时不达标 → 至少升为 **中度**；
- `大卖占比 ≥ lim + 15pct`（默认 `65%`）**且** `评论壁垒 ≥ 1.6×lim`（默认 `8,000`）→ 升为 **重度**。

### 5. 维度 D：新品窗口与本土身份（2 项）

| 指标 | 计算口径 | 默认达标标准 | 维度定级规则 |
| :--- | :--- | :--- | :--- |
| **新卖家占比** | 上架 ≤ 180 天商品的 BuyBox 卖家去重数及新品销额占比 | `新品卖家数 > 10` **或** `新品销额占比 > 20%` | • 达标且 `新品销额占比 ≥ 15%`（或未提取到占比）→ **有窗口**<br>• 达标但 `新品销额占比 < 15%` → **弱窗口**（新卖家多但抢不到销额）<br>• 不达标 → **无窗口**<br>• 待确认/数据不足 → **未知** |
| **本土卖家占比** | 卖家所属地与站点国家一致的有效样本销额 ÷ 所属地已知样本总销额 | `< 20%` | **辅助身份提醒**（不计入垄断/壁垒重度；超标仅提示本土同行已多、本土身份不再稀缺） |

## 三、最终 5 档结论判定标准（按优先级从上到下依次匹配）

| 优先级 | 最终结论档位 | 触发条件 | 建议行动边界 |
| :---: | :--- | :--- | :--- |
| **1** | **数据不足无法判断** | 满足任一：① 总有效已判定指标 `< 50%`；② A1 为「数据不足」；③ 竞争端有效判定 `< 3` 项；④ B 或 C 任一维度有效判定为 0 | 补齐缺失的关键数据后再评估 |
| **2** | **暂不建议进入** | 满足任一即拦截：<br>① **A1 需求底盘 = 不成立**<br>② **B 重度 + C 重度**（双维重度封锁）<br>③ **C 极端（评论壁垒 ≥ 4×） + B ≥ 中度**<br>④ **B 极端 + （C ≥ 中度 或 D = 弱窗口 / 无窗口）**<br>⑤ **（B 重度 或 C 重度） + D = 无窗口**<br>⑥ **（B 重度 + C 中度 或 C 重度 + B 中度） + D = 弱窗口**<br>⑦ **A2 高约束（3 项全不达标） + （A1 偏弱 或 B ≥ 中度 或 C ≥ 中度）** | 明确核心阻断因素，仅在具备极高差异化/低成本冷启动门槛时才值得复评 |
| **3** | **可进入** | **同时满足**：<br>• A1 为健康或偏弱、A2 为可控或轻度约束，且 **A1 + A2 合计不达标 ≤ 1 项**<br>• `趋势方向（站内）` 未不达标<br>• B 与 C 均不超过 **轻度**<br>• D 不为 **无窗口** | 给出首选切入方向与验证重点 |
| **4** | **高风险条件进入** | 未触发「暂不建议进入」，但满足任一单维高风险压制：<br>• B 或 C 存在 **单维重度** 或 **单维极端**（仅靠另一维可控与新品窗口保留空间）<br>• 或 **A2 = 高约束**（CPC / 客单 / 季节全踩线，但核心需求健康且竞争可控） | 必须先人工核实高风险前提（如排除头部大牌/自营造成的“伪新品窗口”、核查价格带/Buy Box/专利壁垒、核算毛利与备货资金周转） |
| **5** | **低风险条件进入** | 以上均未命中时的常规中间态（A1 成立、A2 最高中度约束、B 与 C 最高中度压力、无任何重度/极端封锁） | 明确必须满足的 1–2 个常规差异化或供应链前提 |

## 四、报告与提示词一致性约定

1. **指标名称对齐**：正文与明细表统一使用完整指标名称（例如使用 `上架超3年链接销额占比` 而非 `老品占比`）。
2. **结论前缀硬约束**：AI 输出的 `建议` 必须严格以 `可进入：`、`低风险条件进入：`、`高风险条件进入：`、`暂不建议进入：`、`数据不足无法判断：` 之一开头，禁止仅输出孤立标签。
3. **极端评级展示**：维度 B 或维度 C 触发极端时，拆解表评级列直接显示 `极端`，并在核心证据中标明极端阈值（如 `VC/AMZ近似自营极端控盘(83.4%≥70%)`、`评论壁垒极端高企(27026条≥20000)`）。
